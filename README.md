# Assistant Personnel IA

Une application tout-en-un conçue pour révolutionner votre productivité. Cette application combine la puissance de l'intelligence artificielle pour gérer vos projets, suivre et optimiser le temps passé sur votre téléphone, et vous fournir une équipe entière d'assistants virtuels capables d'effectuer plusieurs tâches en parallèle.

## Fonctionnalités Principales

*   **Gestionnaire de Projets IA** : Un tableau de bord intelligent où l'IA suit, organise et gère l'avancement de tous vos projets à votre place.
*   **Contrôle du Temps d'Écran** : Suivi détaillé de l'utilisation de votre téléphone pour vous aider à rester concentré et à éviter les distractions.
*   **Équipe d'Assistants Multi-tâches** : Lancez plusieurs tâches en même temps grâce à une équipe d'assistants virtuels spécialisés (recherche, rédaction, planification, etc.).

## Structure de l'Application

L'application est divisée en trois onglets principaux, accessibles facilement depuis la barre de navigation inférieure :
1.  **Projets** : Vos projets en cours et terminés, gérés par l'IA.
2.  **Temps d'Écran** : Statistiques et limites d'utilisation de votre appareil.
3.  **Équipe IA** : Interface pour déléguer des tâches à vos différents assistants.

## Démarrage Rapide

Pour lancer l'application sur votre appareil (iOS, Android, ou Web) :

```bash
flutter pub get
flutter run
```
